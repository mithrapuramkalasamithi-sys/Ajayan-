## How to Generate Your Final .APK File in 2 Minutes (Free)

### English Instructions:
1. Extract this ZIP folder on your computer or phone.
2. Go to [GitHub.com](https://github.com/new) and create a new repository (Public or Private).
3. Upload **all files and folders** from this extracted directory into your GitHub repository (make sure the `.github` folder is uploaded too!).
4. Click on the **Actions** tab at the top of your GitHub repository.
5. Wait ~2 minutes for **"Build Clean Ad-Free Android APK"** to finish with a green checkmark ✅.
6. Click on the workflow run and scroll down to **Artifacts** to download `phone-lock-v1.0.0-clean-apk.zip` containing your clean `app-debug.apk`!
